# 🚀 URL Shortener

A clean, reusable **URL shortener website** that lets users turn long URLs into short, shareable links quickly and easily.

🌐 Live Demo: https://url-shortener-seven-orpin.vercel.app/

---

## 📌 What is this?

This project is a **full web application** built with JavaScript and CSS that shortens long URLs into compact ones so you can share them effortlessly. It’s perfect for portfolio showcases and real-world usage! 🌍

---

## 📸 Features

✔️ Shorten long URLs into concise, easy-to-remember links  
✔️ Copy shortened URLs with a click  
✔️ Responsive UI for all screen sizes  
✔️ Clean and simple interface  
✔️ Reusable and deployable on platforms like Vercel  

---

## 🧱 Tech Stack

- **Frontend:** JavaScript, HTML, CSS  
- **Hosting/Deployment:** Vercel

---

## 🛠️ How it Works

1. User enters a long URL in the input field  
2. Project generates a shortened version  
3. Shortened link shows on screen  
4. User can click to **copy** and use anywhere ✂️
