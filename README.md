# 🚀 URL Shortener

The URL Shortener project is a web application designed to shorten long URLs into concise, memorable links. This project utilizes Next.js, a popular React-based framework, and MongoDB for database management. The application provides a simple and intuitive interface for users to create and manage short URLs, making it easier to share links across various platforms.

🌐 Live Demo: https://url-shortener-seven-orpin.vercel.app/

---

## 🚀 Features
* **Short URL Generation**: Create short URLs from long links with a simple API endpoint
* **URL Redirection**: Redirect users to the original URL when they visit a short URL
* **MongoDB Integration**: Store and manage short URLs in a MongoDB database
* **Next.js Framework**: Built with Next.js for server-side rendering and static site generation
* **Tailwind CSS**: Utilizes Tailwind CSS for styling and layout management
* **ESLint and Prettier**: Enforces code quality and formatting with ESLint and Prettier

## 🛠️ Tech Stack
* **Frontend**: Next.js, React, Tailwind CSS
* **Backend**: Node.js, MongoDB
* **Database**: MongoDB
* **Build Tools**: Webpack, Babel
* **Linting and Formatting**: ESLint, Prettier
* **Testing**: Jest, React Testing Library

## 📦 Installation
To get started with the project, follow these steps:
1. Clone the repository: `git clone https://github.com/your-repo/url-shortener.git`
2. Install dependencies: `npm install` or `yarn install`
3. Start the development server: `npm run dev` or `yarn dev`

## 💻 Usage
1. Create a new short URL by sending a POST request to the `/api/generate` endpoint with the original URL in the request body.
2. Visit the short URL to be redirected to the original URL.
